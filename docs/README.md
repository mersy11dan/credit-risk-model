# Portfolio site — Bati Bank Credit Risk

Static case-study site for GitHub Pages.

## Local preview

Open `docs/index.html` in a browser, or from the repo root:

```bash
# Python
python -m http.server 5500 --directory docs
```

Then visit `http://localhost:5500`.

## Deploy on GitHub Pages

1. Push `main` with the `docs/` folder.
2. GitHub → **Settings** → **Pages**.
3. **Source:** Deploy from a branch.
4. **Branch:** `main` / **Folder:** `/docs`.
5. Save. Site URL will look like:
   `https://mersy11dan.github.io/credit-risk-model/`
